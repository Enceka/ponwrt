### 985 API 约定

- airoha_ct_ifc_pool_acquire(pool, io, words, lease)
- airoha_ct_ifc_pool_release(pool, io, lease, consumer_disabled)
- airoha_ct_ifc_pool_recover(pool, io)

均返回 int。io 提供 ctx/read(ctx,slot,words[2])/put(ctx,slot,const words[2])/drain(ctx)。pool 和 lease 零初始化，lease 地址固定，调用方串行化。成功 acquire 输出 lease.mask 和 lease.slot[i]；acquire 失败后 recover 清理部分写入。consumer 发布失败时先确认撤销，再 release；release 失败保留 lease，recover 成功后清空。

容量实测：两 IPv4 加两 IPv6、共享 TCP/端口时占 24 个 tuple 槽，加两个 short guard 共 26；完全不共享需 34，第四次 acquire 零写返回 -ENOSPC。IPv4/IPv6 protocol 的 field24/25 不同，协议谓词不能跨族共享。
